# Daily Stock & Inventory Calculator (ETL)

Проект по восстановлению подневной истории остатков товаров на складах компании на основе исторических транзакций. 

## Описание бизнес-кейса
Бизнесу необходимо иметь актуальный срез остатков товаров на конец любого дня. На входе предоставлены:
1. Стартовый снимок остатков на определенную дату (`stock_2025_04_30.csv`).
2. Журнал сырых транзакций (приходы и расходы) за последующие 3 месяца (`invent_trans`).

Скрипт собирает эти данные, проводит агрегацию и рассчитывает нарастающим итогом точные остатки на каждый день.

## Стек технологий
* **Python 3.13**
* **Pandas** (библиотека для обработки и анализа данных)
* **Pathlib** (модуль для объектно-ориентированной работы с путями файловой системы)

## Особенности реализации (Чему я научился в этом проекте)
Это мой первый масштабный проект с использованием библиотеки **Pandas**, реализованный в рамках ООП:
* **Упаковка в класс (`StockCalculator`):** Вся логика инкапсулирована внутри методов класса. Это позволяет легко масштабировать код (например, в будущем заменить чтение CSV на прямое подключение к базе данных SQL, не ломая математику расчётов).
* **Контроль типов данных:** Для идентификаторов (`item_id`, `location_id`) принудительно задан строковый тип `str`, чтобы Pandas не искажал данные и сохранял ведущие нули.
* **Математика остатков:** Реализована группировка (`.groupby()`) и расчёт кумулятивной суммы нарастающим итогом (`.cumsum()`) внутри уникальных групп "Товар + Склад".
* **Финансовое округление:** Финальные финансовые показатели округляются до двух знаков после запятой для предотвращения ошибок точности плавающей точки (floating-point precision).
